# Quandle GitHub Action

This is the repository for the Quandle GitHub Action. Setup and documentation: [quandle.ai](https://quandle.ai).

**Exposed-file checks.** Quandle only requests files such as `/.env` from a site that proves it belongs to your repository. The job summary shows the one line to publish at `/.well-known/quandle.txt`.
